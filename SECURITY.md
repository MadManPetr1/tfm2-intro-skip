# Security policy

Intro Skip reads and copies local Teamfight Manager 2 save files when its optional mismatch automation is enabled. Please treat any defect that could overwrite, delete, expose, or corrupt user data as security-sensitive.

Report such issues privately through this repository's **Security** tab using **Report a vulnerability**. Do not attach personal save files or paths containing private information to a public issue.

Compatibility problems and ordinary startup bugs can use the public bug-report template.

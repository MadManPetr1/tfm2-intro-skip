[h1]Intro Skip[/h1]

[b]Skip the repetitive startup flow and return to your latest career faster.[/b]

Each startup action can be configured separately, with backup protection available for optional mod-state mismatch handling.

[h2]Features[/h2]

[list]
[*] Skip the startup disclaimer.
[*] Automatically select Continue.
[*] Optionally load through a mod-state mismatch after creating and verifying a backup.
[*] Choose automatic backup retention from 3 to 30 days.
[*] Manually recover from the latest verified backups.
[/list]

Automatic mismatch handling can remain disabled while still using the disclaimer skip and auto-continue features.

[h2]Compatibility[/h2]

[b]Tested with:[/b] TFM2 0.5.8

Compatibility with later game versions is not guaranteed until confirmed.

[h2]Setup[/h2]

[list]
[*] Subscribe to and enable Intro Skip.
[*] Open its settings and choose the startup actions you want enabled.
[*] Restart the game when prompted.
[/list]

[h2]Backup protection[/h2]

Before the optional Load Anyway action is used, the mod creates and verifies a backup. Recovery imports always remain manual.
